# Acceptance — {{PACK}}

## Per task

1. The changed files are inside the brief's Owns.
2. The brief's meaningful tests were run and their observed results are recorded.
3. STATUS is `needs-review`; REPORT contains a three-line result summary, changed files, commands/results and any
   remaining work.
4. The senior reads the bounded diff, repeats the checks needed for confidence, and records pass or changes.

A worker's report is a handback to verify. Do not treat a claim as proof merely because the worker finished.

## Final acceptance

Describe only the pack-level checks that are needed beyond the task briefs. Evidence files and hashes are optional
unless GOAL, RULES, a brief or the workspace policy explicitly requires them.
